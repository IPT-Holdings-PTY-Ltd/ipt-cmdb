# Changelog

All notable changes to IPT CMDB are documented here.

## [0.1.0] - 2026-07-10

### Added

- Multi-tenant MSP/customer workspace and scoped role model.
- ITIL-aligned asset metadata, lifecycle ownership, renewal, and end-of-life tracking.
- Interactive relationship topology with impact-oriented CI visualisation.
- Root-level customer groups, RBAC preview, branding, database configuration, and backup/restore.
- PostgreSQL compatibility persistence, canonical schema, reconciliation helpers, Docker image, and Azure configuration.

### Security

- Server-enforced company scope and root-only administrative functions.
- Review-gated integration boundary and explicit Passportal metadata-only policy.
